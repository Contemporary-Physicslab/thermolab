
# Start je eigen repository


## Instructies voor de repository-eigenaar
1. Ga naar de [repository](https://github.com/Contemporary-Physicslab/thermolab)
1. Klik op de groene knop `Use this template` en kies `Create a new repository`
1. Kies een goede naam voor je repository – deze wordt ook onderdeel van de URL! Wijzig de overige instellingen niet en klik op `Create repository`.

Je repository wordt nu aangemaakt op basis van de template-repository.

Voordat je website zichtbaar is, moeten we GitHub Pages inschakelen.

## GitHub pages inschakelen
GitHub Pages inschakelen via Actions:

- Ga naar 'Settings' (bovenaan in het midden van het scherm) en klik op 'Pages'. Kies in het keuzemenu onder 'Build and development' voor 'GitHub Actions' als bron.
- Klik linksboven op 'Code' en vervolgens op het tandwielicoon (⚙, naast 'About') aan de rechterkant van de pagina. Vink het vakje 'Use your GitHub Pages website' aan.
- Als er een GitHub Action aanwezig is (in de map `.github/workflows`), wordt de site bij elke nieuwe commit naar GitHub opnieuw opgebouwd.

## Main branch beschermen
Volg [deze stappen](https://contemporary-physicslab.github.io/FYPLC/branch-rules/) om de main branch te beschermen.


## Je partner uitnodigen
Voor IP2 werk je in tweetallen. Je kunt je partner(s) uitnodigen om samen aan je repository te werken. Ga hiervoor naar je nieuwe repository op GitHub en volg de onderstaande stappen.

1. Ga naar je nieuwe repository op GitHub.

1. Klik op **Settings** (rechtsboven in het scherm) en klik op **Collaborators** in het menu aan de linkerkant.

1. Klik op de knop **Add people** onder het kopje "Manage access".

1. Typ de gebruikersnaam van je partner (of partners) in en klik op **Add <username> to this repository** (waarbij `<username>` de gebruikersnaam van je partner is).

## Partner accepteert de uitnodiging
Je partner ontvangt een e-mail met een uitnodiging om samen aan de repository te werken. Zodra de uitnodiging is geaccepteerd, kunnen jullie beiden wijzigingen aanbrengen in de repository.
